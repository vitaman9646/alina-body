## Ключевые скрипты (в git, scripts/)

- `parse_pdf.py` — универсальный парсер PDF (авто-порог заголовков, dedup, картинки через pymupdf). Под `.venv-tts/bin/python`.
- `gen_tarelka.py`, `gen_dnevnik.py`, `gen_psihologia.py`, `gen_faq.py`, `gen_menu.py`, `gen_spisok.py` — генерация карточек лид-магнитов (kie.ai иллюстрации + Pillow-вёрстка + загрузка в Supabase).
- `pin_guide.py` — УНИВЕРСАЛЬНЫЙ закреп: `python3 pin_guide.py --title "…" --urls /tmp/x_urls.json --lonrid path.txt` (карточки-ссылки + лонгрид + пин).
- `post_matrix.py` — постинг матрицы (FIFO, идемпотентно, `matrix_sort_key` по дате в имени).
- `post_day.py` (контент-план Threads+IG), `reply_comments.py` (авто-ответы), `publish_articles.py` + `post_telegram.py` (статьи), `post_tip.py` (совет дня).

## Стратегия Threads (с 2026-10-20, по курсу SWBAND)

Threads = текстовая соцсеть: **фото/видео режут охваты → посты только текстом.** Ежедневный контент = хуки-ячейки матриц (лид-магниты) + ссылка на пост лид-магнита первым реплаем. Instagram остался визуальным (1 фото/день). Правила и 33 формулы — в `content/threads-formulas.md`, структура лонгрида — `content/lead-magnet-lonrid-template.md`. Реплай-ссылка — отложенная (+2 часа): очередь `content/threads-matrix/pending_replies.json`, cron `*/10 * * * *` выстреливает `post_matrix.py --reply-pending`. Если Алина уже дала ссылку в комментарии (ответ на «дай сборник») — отложенная ссылка отменяется (`reply_comments.py` → `cancel_pending_reply`). Лид-магниты будут пополняться постоянно (у владельца много курсов).
